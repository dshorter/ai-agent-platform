## THE LIVE BLOCKER

**Synthesis cannot be run reliably at full selection size.** Two failure modes,
only one understood:

1. **Ceiling blown on an immediate answer** — 1 iteration, 0 tools, exactly
   20,000 output tokens, **zero characters emitted**. Reasoning and the answer
   share one output pot. `scout_agent.py`'s header has said so since August and
   named the fix: **stream this stage, or give reasoning its own budget.**
   Raising the ceiling buys a larger silence.

   > **FIXED 2026-09-06, and half that sentence was never true.** There is no
   > second option: `budget_tokens` is removed on Sonnet 5 and returns a 400.
   > The line survived its own 09-05 correction — which was about whose hazard
   > it is, not whether the remedies existed — because a fix that is named but
   > never attempted is never checked. Synthesis now streams at 64,000, and
   > `output_config.effort` (`SCOUT_SYNTHESIS_EFFORT`, default `high`, the
   > API's own default) is the only depth control. **Mode 1 is closed;
   > mode 2 below is not.**
2. **Roamed, ended cleanly, pitched nothing** — 7 iterations, 6 tools,
   `end_turn`, output well under budget, 0 leads. **Same shape as the two runs
   that worked.** Unexplained. The evidence capture was added after these ran,
   so the next occurrence will be diagnosable.

Do not spend on a full-selection arm until (1) is fixed. *(Fixed 09-06 —
next step is a 250-jewel test, not a full arm.)*

## Mistakes worth not repeating

- **`pgrep -f "pipelines.scout"` matches the waiter's own command line.** Cost 40
  minutes of believing a finished run was still going. Use `[p]ipelines`.
- **Do not pipe a paid run through `tail` or `grep`.** Destroyed two results;
  one had to be re-bought.
- **Test a prompt change on a 250-jewel selection before a full one.** I spent
  $1.64 discovering a failure a $0.40 run would have shown.
- **Two failures with the same symptom are not one bug.** I called a 2-vs-2
  pattern decisive, blamed my own edit, reverted it — and the control refuted
  me. It was two modes with one symptom.
- **A hazard filed under a name that stops applying gets orphaned.** The
  thinking-budget warning was written as a *Fable* caveat; the seat moved to
  Sonnet and the warning went with the model instead of staying with the seat.
  Fourth instance this week of the same shape.
